# TaskFlow — Modern To-Do App

A sleek, responsive, and intuitive To-Do application built with vanilla HTML5, CSS3, and JavaScript. Effortlessly manage your daily tasks with priority tagging, due-date tracking, quick-add input, dynamic search, and seamless dark/light mode.

---

## ✨ Features

- **⚡ Quick Task Entry**: Type and press <kbd>Enter</kbd> to add tasks instantly, or open the detailed modal for full control.
- **🎯 Task Prioritization**: Mark tasks as **High** (🔥), **Medium** (⚡), or **Low** (🌱) with color-coded side indicators and badges.
- **🏷️ Categories**: Categorize tasks into **Work**, **Personal**, **Study**, or **General**.
- **📅 Due Dates & Reminders**: Automatically calculates and highlights **Overdue**, **Due Today**, or upcoming deadlines.
- **🔍 Real-Time Search**: Instant search matching task titles and descriptions with a one-click clear button. Press <kbd>/</kbd> to jump directly to search.
- **📊 Progress Tracking**: Live statistics displaying total tasks, active tasks, completed tasks, and an animated progress bar.
- **🌗 Dark & Light Themes**: Smooth theme switcher with automatic preference persistence.
- **💾 Local Storage Persistence**: All tasks, status changes, and settings persist automatically in your browser.
- **🔔 Hourly Task Reminders**: Automatically sends notifications repeating every hour for incomplete tasks until marked completed. Supports native browser notifications, soft Web Audio chimes, and interactive in-app toasts with quick "Mark Done" actions.
- **📱 Responsive Glassmorphic Design**: Tailored for desktops, tablets, and smartphones.

---

## 🚀 Getting Started

1. Simply open `index.html` in any modern web browser (Google Chrome, Firefox, Microsoft Edge, Safari).
2. No servers, build tools, or dependencies required!

---

## ⌨️ Keyboard Shortcuts

| Shortcut | Action |
| :--- | :--- |
| <kbd>/</kbd> | Focus the Search bar |
| <kbd>Enter</kbd> | Submit quick-add task or modal form |
| <kbd>Esc</kbd> | Close active modal |

## 🛠️ Tech Stack

- **HTML5**: Semantic layout and accessible structures
- **CSS3**: Custom CSS variables, Flexbox & Grid, Backdrop filter (Glassmorphism), fluid animations
- **JavaScript (ES6+)**: Vanilla DOM manipulation, LocalStorage API, custom event handling
- **Typography**: Google Fonts (*Plus Jakarta Sans* & *Outfit*)
